# 📈 股票推荐系统

基于历史涨停数据的智能股票推荐工具，通过多时间段回测分析，为您推荐高潜力股票。

## ✨ 核心功能

- **多时间段策略回测**：分析全历史、近3月、近1月的策略胜率
- **策略衰减检测**：自动识别策略失效，及时提醒风险
- **智能风险评级**：对每只股票进行风险评估（高/中/低）
- **动态仓位建议**：根据胜率自动推荐合理仓位
- **热门板块追踪**：实时获取市场热点概念和行业
- **详细报告生成**：自动生成包含推荐理由和风险提示的TXT报告

## 🚀 快速开始

### Windows用户

1. **下载项目**
   ```bash
   git clone https://github.com/你的用户名/stock-recommender.git
   cd stock-recommender
   ```

2. **一键安装**
   - 双击运行 `install.bat`
   - 等待依赖安装完成

3. **开始使用**
   - 双击运行 `run.bat`
   - 或在命令行执行：`python stock_recommender.py`

### Mac/Linux用户

1. **下载项目**
   ```bash
   git clone https://github.com/你的用户名/stock-recommender.git
   cd stock-recommender
   ```

2. **一键安装**
   ```bash
   chmod +x install.sh
   ./install.sh
   ```

3. **开始使用**
   ```bash
   chmod +x run.sh
   ./run.sh
   ```
   或直接运行：`python3 stock_recommender.py`

## 📋 系统要求

- Python 3.8 或更高版本
- 稳定的网络连接（用于获取实时数据）

## 📦 依赖包

- `akshare` - 获取A股市场数据
- `pandas` - 数据处理和分析
- `requests` - 网络请求

所有依赖会在运行安装脚本时自动安装。

## 📊 使用说明

### 运行时间建议

- **交易日 15:00 之后**：分析当日首板，推荐次日买入
- **交易日 15:00 之前**：分析前一日首板，推荐当日买入

### 报告解读

运行后会生成 `stock_report_YYYYMMDD_HHMMSS.txt` 报告，包含：

1. **策略有效性分析**
   - 最优策略名称
   - 全历史/近3月/近1月胜率对比
   - 策略衰减警告

2. **推荐股票明细**
   - 股票代码和名称
   - 风险等级（🔴高 / 🟡中 / 🟢低）
   - 关键指标（市值、换手率、封板时间）
   - 推荐理由和风险提示

3. **仓位管理建议**
   - 基于胜率的单只股票仓位建议
   - 风险控制提示

4. **操作建议**
   - 止损策略
   - 卖出时机
   - 注意事项

### 风险等级说明

- 🔴 **高风险**：小市值 + 超高换手 + 尾盘封板
- 🟡 **中风险**：部分风险因素存在
- 🟢 **低风险**：各项指标相对稳健

## ⚙️ 策略说明

系统内置两种策略，自动选择历史表现最优的策略：

1. **高换手+小市值+早封**
   - 换手率 > 20%
   - 流通市值 < 50亿
   - 10:30前封板

2. **换手+热门行业**
   - 换手率 > 15%
   - 属于当前热门概念/行业

## 🔧 常见问题

### Q: 安装失败怎么办？

**A:** 尝试手动安装依赖：
```bash
# Windows
pip install -r requirements.txt

# Mac/Linux
pip3 install -r requirements.txt
```

### Q: 提示网络错误？

**A:** 
- 检查网络连接是否正常
- 部分数据源可能需要科学上网
- 稍后重试，可能是数据源临时故障

### Q: 没有推荐股票？

**A:**
- 可能当日无涨停股票
- 可能是非交易日
- 检查是否是周末或节假日

### Q: 胜率为什么这么低？

**A:**
- 涨停板次日连板本身就是低概率事件
- 8-10%的胜率在统计学上已经具有参考价值
- 重点关注风险控制和仓位管理
